# CalendarList

This project is designed to allow me to manage homework due dates and make my note taking more efficient. 
The design philosophy is connection. I want to be able to connect todolists and notes to dates and classes.

# Assignment Milestones
Note taking service
Notes can connect to specific objects. (Can connect a note into a class, times or a person)
Can view connected notes on certain topics
Can add tags to notes and filter them by dates
ToDo Lists exist and appear and disappear upon being checked
Weekly overview that shows a timeline
ToDo priorities and specifications like estimated completions
ToDos can be added into notes.

# Future Plans (V2.0)
